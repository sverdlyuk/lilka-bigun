# Бігун

Маленька нескінченна гра-раннер для консолі [Лілка](https://lilka.dev), написана на Lua. Ти — зелений чоловічок, який біжить зеленим пагорбом і не має наміру зупинятися. Назустріч летять равлики, черв'яки та жабки, а згори дзижчать бджоли. Твоя справа проста: вчасно стрибати й пригинатися, щоб пробігти якнайдалі.

Я зробив цю гру як навчальний приклад: тут на пальцях видно, як працюють спрайти, анімація ходьби, прокрутка фону та звук. Коду небагато, і він навмисно простий — щоб можна було прочитати, зрозуміти й переробити під себе.

## Як грати

Чоловічок біжить сам — ти лише керуєш тим, як він уникає перешкод. Наземних ворогів (равлик, черв'як, жабка) треба перестрибувати, а бджолу, що летить на рівні голови, — пропускати над собою, пригнувшись. Що довше біжиш, то швидшою стає гра, тож розслаблятися не вийде.

| Кнопка | Дія |
|--------|-----|
| A або вгору | стрибок |
| вниз | пригнутися |
| START | пауза |
| B | вихід |

Врізався у ворога — гра закінчується, лишається натиснути A і почати заново.

## Як запустити на Лілці

Скопіюй усю теку `bigun/` (разом із підтекою `resources/`) на SD-карту, встав картку в Лілку й запусти `bigun.lua` через Keira. Головне — щоб `resources/` лишалася поряд зі скриптом: саме звідти гра бере картинки й звуки.

## Як воно влаштовано

Гра тримається на трьох звичних для Лілки функціях: `init` готує ресурси один раз, `update` щокадру рухає світ і перевіряє зіткнення, а `draw` малює картинку. Усі вороги описані однією таблицею — щоб додати нового, достатньо дописати один рядок із його кадрами й «доріжкою» (землею чи повітрям). Фон їде завдяки простому трюку: він намальований двічі поруч і плавно зсувається, а коли одна копія ховається за краєм — миттєво повертається назад, і виходить нескінченна стрічка, як бігова доріжка.
